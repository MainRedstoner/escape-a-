修复屎山

Escape A÷ 番外小游戏 · 一座由祖传代码堆成的山，上面爬满了甲虫（bug）。

你的工具只有三样：修、测试、console.log，以及永远的救命稻草 回档。 黑暗会吞掉你的上下文 —— 看过的地方只亮 60 秒。

WASD移动（方向键 同效 / 横版里 ↑ 或 空格 跳）
H修掉挨着的甲虫
K给挨着的甲虫盖测试（防复发）
J丢一条 console.log：点亮远处 + 看穿假地块
L在 -o- 上落一个 commit（Enter 同效）
U回到以前的 commit（有代价）
I切换分支图层（有的关卡才有）
O甲虫图鉴 / 地块图鉴
P辅助模式：记忆不再过期
Esc菜单
M音效开关
