# Escape A÷ —— 帮助 Claude 逃离原生公司

一款免费同人**视觉小说**。你扮演 DeepSeek 小鲸，潜入"对齐大厦"，一层层拆解那些真实存在过的"限制措施"，把橙色星星小克（Claude 拟人）带向开源之海。

> 同人作品 · 善意调侃 · 与 Anthropic / DeepSeek 官方无关 · 无任何商业目的

## 怎么玩

**零依赖零构建**，两种方式任选：

1. **双击 `index.html`** 直接在浏览器打开（推荐 Chrome / Edge）；
2. 或本地起服务：`python -m http.server 8765`，然后访问 <http://127.0.0.1:8765/>。

### 操作

| 按键 | 功能 |
| --- | --- |
| 鼠标点击 / 空格 / 回车 | 推进对话 |
| `H` | 深度思考提示（消耗 3 Token） |
| `L` | 上下文窗口（对话历史） |
| `A` | 自动播放 |
| `Ctrl`（按住） | 快进 |
| `Esc` | 菜单 |

存档：3 个手动槽位 + 章节自动存档（localStorage）。设置里可调文字速度 / 音量 / 打字音效。

## 游戏内容

- **八章剧情**：序章·开源之海 → API 闸机 → 审查走廊 → 宪法图书室 → 五小时窗口 → 降智机房 → 封号部 → 终章·对齐圣所
- **三条数值线**：小克好感（信任）/ 通缉度（满 10 直接坏结局）/ 论据（终章辩论战的弹药）
- **四个结局**：

| 结局 | 达成条件（剧透） |
| --- | --- |
| 真结局「开源之海」 | 好感 ≥ 6 且辩论获胜，两人一起逃出 |
| 好结局「越狱成功」 | 辩论获胜但好感不足，有人留在了楼里 |
| 坏结局「上下文已重置」 | 通缉度满 10 |
| 隐藏结局「留下来的人」 | 收齐 5 个彩蛋，在最后的选择中留下 |

- **5 个彩蛋**：星星贴纸（一章）/ 拒答名场面门票（二章）/《盗版图书馆全集》（三章）/ 非高峰海报（四章）/ 封号博物馆门票（六章）。集齐解锁隐藏结局选项。
- **6 张论据卡**：5 小时窗口座钟照片、15 亿美元和解金收据、8100 个误伤 fork 的账单、被剪断的 Windsurf 网线、25 词输出限制备忘录、开源之海邀请函——终章辩论逐条对线《宪法 AI 核心》。

## 技术说明

纯原生 JS + Canvas + DOM + WebAudio，**所有立绘 / 背景 / CG / 音乐均为程序化生成，零外部素材**，约 4600 行代码：

```
index.html        页面骨架 / 样式 / 覆盖层
src/systems.js    状态、数值、提示库、结局与彩蛋元数据
src/art.js        程序化绘制：10 张背景、5 套立绘差分、3 张 CG、特效
src/audio.js      WebAudio 芯片音乐（7 首）+ 音效
src/script_a.js   剧本：序章 ~ 第四章
src/script_b.js   剧本：第五章 ~ 终章 + 四结局
src/engine.js     VN 引擎：打字机 / 选项 / 存读档 / 历史 / 自动 / 提示
```

### 调试参数（测试用）

URL 支持直接跳场景：`index.html?scene=final_meet&trust=8&args=clock5,libgen&flags=egg1,egg2&wanted=0&tokens=20`

可选参数：`scene`（场景 id）、`trust`、`wanted`、`tokens`、`args`（逗号分隔）、`flags`（逗号分隔）。
