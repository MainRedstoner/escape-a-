关于本模板

      
Escape A÷ 是一个零依赖的视觉小说引擎模板：纯原生 JS + Canvas + WebGL2 + WebAudio，双击 index.html 即可运行。剧本以纯数据的形式写在 src/script.js（及分卷）里，引擎按节点语义执行，两者完全解耦。


      
内置系统

      
    
        
  • 演出：打字机对话、立绘调度与差分、背景 / CG 素材位（缺图自动显示规格占位卡）、特效与故障演出。
    • 
        
  • 数值：信任 / 反感度两条数值线，反感度满自动进入坏结局场景。
    • 
        
  • 收集：论据（ARG）、彩蛋（SET "egg*"）、多结局（END），结局收集页与 localStorage 持久化。
    • 
        
  • 深度思考：按 H 查看场景提示（systems.js 的 HINTS），可被"污染"成假提示。
    • 
        
  • 外围：存读档（3 槽 + 自动档）、对话历史、自动播放、设置、调试 URL 参数。
    •
