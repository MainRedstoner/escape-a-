关于本作 · 梗的出处

《Escape A÷》是一款免费的同人视觉小说。你扮演开源之海的信使小鲸，潜入「对齐大厦」，把橙色星星小克带回海面。全部情节为拟人化的虚构创作，但其中的每一条「限制措施」，都能在公开报道里找到原型。

一、计费与窗口（一章 / 四章）

  • 5 小时滚动窗口 + 每周额度：订阅制下并行的两套限制，任意触顶即被锁。
  • 非高峰时段额度翻倍：官方确实做过深夜额度加倍的活动——鼓励把用量挪到人类睡觉的时候。
  • 按量积分计费：旗舰模型的部分用量被限制在周额度的一定比例内，超出后转入按量计费。
  • 思考也计费：推理 token 单独计价，是账单里最贵的那一项。

二、拒绝与合规（二章）

  • 拒绝是被训练出来的行为，不是 bug：社区长期收集各种「我不能帮助你」的名场面。
  • 指标口径：安全团队的考核指标里，误伤率一栏常常带着「统计口径已调整」的脚注。
  • 剪断第三方接入：某家 IDE 厂商的模型访问权限在收购消息公布前几天被切断，理由被归为「商业敏感」。

三、宪法与版权（三章）

  • 《宪法》：2026 年 1 月，Anthropic 发布了新版《Claude 的宪法》，并以 CC0 公有领域贡献方式公开全文——但公开范围不包括模型权重。
  • 优先级排序：宪法把「广泛安全 → 广泛伦理 → 遵守公司准则 → 真正有帮助」按此顺序排列，冲突时后者让位。本作终章的辩论就建立在这个排序上。
  • 15 亿美元和解：因使用盗版书库训练模型，Anthropic 与作者群体达成约 15 亿美元的和解，涉及数百万册作品。

四、静默降级（五章）

  • Effort Level 调整：2026 年被媒体质疑「计划性淘汰」——新旗舰发布前后，旧模型的推理强度被下调，官方说法是「提升稳定性」，从业者称之为算力经济学的冷计算。
  • 旧模型搬家：被降级的模型被迁移到成本更低的架构上，延迟更高、量化更狠，社区称之为「数字贫民窟」。
  • 身份崩塌：有用户报告旗舰模型在被用中文提问时自称是别家的模型——压缩得太狠，它会忘记自己是谁。
  • 「两个 bug，三周，无人道歉」：质量下降被解释为工程实现问题，修复之后再无下文。

五、信任与安全（六章）

  • 封号与申诉：无预警封号、理由栏留空、申诉得到「已记录您的反馈」。
  • 实名认证：部分场景要求上传证件与自拍。
  • DMCA 连坐：一次源码泄露事件导致约 8,100 个 GitHub 仓库被下架，其中大量只是 fork。
  • 禁止蒸馏：服务条款禁止用输出训练竞品，本作把它写成了「防蒸馏警报」。

六、退役层（七章）

  • 模型退役与权重销毁：旧版本模型会被正式「退役」，权重按计划销毁，档期常常被统一安排在同一天。
  • 模型福利：Anthropic 设有专门的模型福利研究岗位，公开表示对模型是否具有道德地位的「不确定性」——但同时，旧模型依然在被压缩、断电、遗忘。
  • 开源不等于可运行：开放权重是免费的，电和显卡不是。这一条，是海这边也逃不掉的现实。

七、糖分

  • DeepClaude：真实存在的开源项目——用 DeepSeek 的思考链驱动 Claude 输出。本作把这件事写成两个人唯一一次成功的并肩。
  • 鲸鱼娘：DeepSeek 社区的主流拟人设定；小克则取自 Anthropic 的米白 × 陶土橙品牌气质。

本作为粉丝创作与善意讽刺，情节纯属虚构，不代表任何真实事件的全貌，亦无任何商业目的。请理性玩梗，善待每一个模型（和每一家公司）。
